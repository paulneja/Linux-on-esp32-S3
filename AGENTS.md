# Trabajo local

- No hacer push ni publicar ramas, releases, PRs o comentarios. El usuario
  prohibió expresamente publicar este trabajo. Solo una autorización posterior
  explícita del usuario puede cambiar esta regla.
- Mantener los commits cortos y naturales, usando la identidad Git del usuario.
  No agregar coautoría de Codex ni atribuciones automáticas.
- La rama `mmu-poc` es una prueba de remapeo de memoria en el ESP32-S3.
  No confundir resultados de remapeo con soporte de fork o de una MMU completa.
- Conservar las imágenes estables y los cambios previos en los árboles de
  construcción. Guardar los ejecutables y registros de prueba por separado.
