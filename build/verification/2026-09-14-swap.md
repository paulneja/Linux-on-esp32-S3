# The page-set exchange on a board that no longer lies: 20 of 20

The bank swap (`experiments/mmu-poc/fork/swap-banks.patch`) was switched off
on 2026-09-12 for corrupting memory and written off on 2026-09-13 after
measuring 2 FAIL / 1 PASS / 7 INCONCLUSIVE against the copy model's
2 / 5 / 3 with its accounting proven correct (incident 16). The next day the
corruption was found in the firmware -- no flash-cache invalidation after any
write Linux makes, incident 15 -- and fixed. This is the swap measured again
on that firmware.

## What was measured

Kernel built by `build-kernel-reclaim.sh` with `FORK_SWAP_BANKS=1` from the
tree of the 2026-09-14 clean build: current config (`PREEMPT_NONE`,
`SLUB_TINY`), the four context-switch fixes, the orphan list and the
inconsistency latch. `xipImage` SHA-256
`aa8560a7f1e4af6a43a1b2abaa67fa52bc3b58988dd582848f0c0aa74460d17a`. Rootfs,
`/etc` and `/home` artifacts of `27027d4`. Firmware with the cache fix.
`build/soak-boot.py --rounds 20`, with a probe reading the fork counters at
every login.

## Result

**0 FAIL, 20 PASS, 0 INCONCLUSIVE.** Every round logged in, read `dmesg` and
`/proc/sys/kernel/tainted` (`0` in all twenty) back, and answered the probe.
The inconsistency latch (`nommu_bank_broken`, reported by
`bank_report_broken()` at the next fork or exit) fired in **no** round.

The exchange was doing the work, not sitting idle: `ForkSwitchMax` between
13 800 and 14 278 µs in every round (a context switch exchanging up to the
full banked set), `ForkRecovered` 236 kB at every login. Summary in
[`2026-09-14-swap-soak.json`](2026-09-14-swap-soak.json).

| | copy model, fixed firmware | swap, fixed firmware |
|---|---|---|
| 20 factory boots | 20 PASS (`2026-09-14-cache-fix.md`) | **20 PASS** |
| latch | n/a | never fired |
| `test-reclaim.py` host model | passes | passes |

## What changed in the repository

`FORK_SWAP_BANKS` defaults to `1` in `build-kernel-reclaim.sh`;
`container-build.sh` does not set it, so the clean build carries the swap.
`process-test.c` already detects the model through `ForkSwitchMax` and checks
the resident-owns-nothing invariant under it. `FORK_SWAP_BANKS=0` builds the
copy model.
