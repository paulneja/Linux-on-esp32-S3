which built the sources the 0.8 tag carries; the tag's own commit adds only
these images, this record and the lines of `build/README.md` that name them. The run's manifest names the source commit
`e91c2be`, which is `13c85d6` in this history. The run built it twice in
two fresh containers and compared every artifact
([`2026-09-14-release-reproducibility.json`](2026-09-14-release-reproducibility.json)):

combined image differ in one file, `/etc/shadow`, from the random salt of

## What was on the board

The board runs in [`2026-09-14-final-image.md`](2026-09-14-final-image.md)
(36/36, extra tests 10/10, soak 10/10, then driven from a host over WiFi)
used the clean build of `8ea9011`, `7b4c94e` in this history. Between that commit and `13c85d6` the
build inputs changed only in comments: the kernel config, the cmdline patch,
the firmware patch, `jobq.c`, the build scripts and the overlay scripts
(`git diff 7b4c94e 13c85d6` shows no code line). The
one functional change, `wifi connect` writing its configuration, was
verified on the board from the host before it was committed. These exact
bytes have not been flashed yet; the next board run does that.
