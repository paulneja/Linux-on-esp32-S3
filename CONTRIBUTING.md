# Helping out

This is a small hobby project, so any help counts.

- **Found a bug?** Open an issue with what you did, what you expected and
  the boot log. `bootlog verbose` and a reboot give you the full one.
- **Tried another board?** Whether it worked or not, an issue saying so is
  gold. Mention the module, the flash chip and the PSRAM size.
- **Code or docs?** PRs are welcome. Small ones, one thing each. If it
  touches the kernel or the firmware, say how you tested it on a board.
- **Security?** Read [SECURITY.md](SECURITY.md) first.

And if this saved you a weekend and you feel like it, you can
[chip in here](https://donation.streamiverse.io/paulneja). Totally optional,
the project stays free either way.
